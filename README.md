# Login Form

A clean, responsive HTML/CSS login form demo built with plain HTML and CSS. This repository contains a small, single-page login form example that you can open in your browser or use as a starting point for your own projects.

![Login Form Screenshot](./Screenshot%202024-08-10%20231807.png)

## Features

- Simple and modern login UI
- Responsive layout
- No JavaScript required (pure HTML & CSS)
- Includes a scenic background image used in the design

## Files

- `index.html` — The login form markup
- `style.css` — Styles for the form and layout
- `Screenshot 2024-08-10 231807.png` — Screenshot used in this README
- `view-natural-mountain-formation-with-dreamy-aesthetic.jpg` — Background image used in the design

## Preview

Open `index.html` in your browser to see the form live. The screenshot above shows the default look.

## Run locally

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Login-Form-106.git
2. Open the folder and open `index.html` in your browser, or run a simple local server:

   - Python 3:
     ```bash
     python -m http.server 8000
     # then open http://localhost:8000 in your browser
     ```

   - Node (http-server):
     ```bash
     npx http-server -p 8000
     # then open http://localhost:8000
     ```

## Customization

- Update `style.css` to change colors, spacing, or responsive breakpoints.
- Replace the background image (`view-natural-mountain-formation-with-dreamy-aesthetic.jpg`) with your own to change the look.
- Add JavaScript to handle form submissions or integrate with a backend.
